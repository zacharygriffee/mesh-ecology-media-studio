# Media Studio Doctrine

The local layer is allowed to be useful. It is not allowed to quietly become
shared durable truth.

Studio must label local records honestly:

- local receipt
- local draft
- local decision
- local cache
- not mesh truth
- not distributed proof
- not ratified shared state

Local filesystem records may be used for source media, generated media,
accepted or rejected bins, proxies, thumbnails, waveforms, rough exports, and
draft cards.

Explicit descriptors and evidence are required for asset identity, provider
lineage, prompt/card lineage, review decisions, acceptance/rejection,
continuity claims, export receipts, and byte references.

Provider API results are inputs to evidence. They are not authority by
themselves.
