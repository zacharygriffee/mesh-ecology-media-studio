# Causal Continuity Posture

Studio records causal-shaped fields early so later adapters can map media work
into continuity interpretation.

The future adapter name is:

```text
media-causal-adapter
```

The initial local records may include:

- parent refs
- referents
- branch ids
- context ids
- observer or operator ids
- continuity claims
- transition summaries

`causal-substrate` remains optional. Studio does not use it as a database,
event log, job queue, truth engine, consensus layer, or mandatory runtime.
