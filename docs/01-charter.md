# Charter

`mesh-ecology-media-studio` exists to model media production work in mesh
ecology without forcing media semantics into Edge, Packs, Bytes, or
causal-substrate.

Studio owns:

- media cards, shots, scenes, and references
- provider job requests and provider result descriptors
- generated candidates and media asset descriptors
- ingest, review, acceptance, rejection, and export evidence
- continuity evidence and causal-shaped lineage fields
- byte references as media asset references, not authority

Studio begins with local project folders and explicit JSON descriptors. Later
phases may publish byte references and mesh-facing evidence through proper
proposal, PUB/RAT, and ratification flows.

The first product label is **Studio**. The domain name is `media-studio`.
