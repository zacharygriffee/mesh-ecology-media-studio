# Charter

`mesh-ecology-media-studio` exists to make mesh-ecology media production
inspectable, portable, reviewable, replicable, and eventually mesh-compatible
without forcing media semantics into Edge, Packs, Bytes, Layer, mesh-v0-2, or
causal-substrate.

Studio owns:

- media cards, shots, scenes, and references
- provider job requests and provider result descriptors
- generated candidates and media asset descriptors
- ingest, review, acceptance, rejection, and export evidence
- continuity evidence and causal-shaped lineage fields
- byte references as media asset references, not authority
- inference-source posture for operator-supplied media, provider adapters,
  Edge agent seats, local inference, future Agent Bridge/BYO-AI lanes, and
  mesh-facing source proposals
- production package evidence, render plans, review decisions, receipts, and
  handoff candidates as local records rather than loose files

Studio begins with local project folders and explicit JSON descriptors. Later
phases may publish byte references and mesh-facing evidence through proper
proposal, PUB/RAT, and ratification flows.

Studio can perform simple media work, including image handling, rough cuts,
basic audio/video preparation, and export planning, but those are capabilities,
not its purpose. A plain agent can run a tool; Studio exists to coordinate the
operator decisions, source posture, evidence, reviews, lineage, and future
family seams around those tools.

Studio does not route runtime work. Edge/operator owns runtime initiation,
dispatch, agent-seat mediation, and return/status surfaces. Spine is
build/doctrine/coordination context for the repo family; it is not runtime
routing, dispatch, or production authority.

The first product label is **Studio**. The domain name is `media-studio`.
