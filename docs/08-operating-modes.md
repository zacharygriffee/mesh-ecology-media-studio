# Operating Modes

## Mode 0: standalone-local

No Edge required. Studio uses a project folder, local descriptors, local media
files, and local receipts. This mode is useful by itself.

## Mode 1: edge-mediated

Edge can consume exported work packets, evidence, readiness records, and
operator decision requests. Edge organizes operator attention. Studio keeps
media semantics.

## Mode 2: mesh-mediated

Media descriptors, byte references, proposals, PUBs/RATs, and ratification
flows become mesh-facing through explicit authority lanes.

## Mode 3: distributed production

Multiple devices, actors, providers, ratifiers, and operator surfaces cooperate
with explicit boundaries between media work, byte materialization, operator
attention, and mesh truth.
